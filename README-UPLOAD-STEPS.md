# bfcmhostingdeals.site – upload steps (v8)

1. Unzip this file on your computer first. Do not upload the .zip itself.
2. Upload everything inside (all folders + index.html, 404.html, sitemap.xml, robots.txt,
   llms.txt, og-image.png, favicons) to the root of the GitHub Pages repo, replacing old files.
3. Keep the CNAME file in the repo as it is.
4. After deploy, purge the Cloudflare cache.
5. In Google Search Console, resubmit https://bfcmhostingdeals.site/sitemap.xml
